DeepFace 人脸识别演示 · 免安装版
============================================

【怎么用】

1. 双击「双击运行.bat」
2. 程序会自动分析「照片」文件夹里的所有图片
3. 识别结果直接显示在黑色窗口里，标注图输出到「结果图」文件夹
4. 想分析自己的照片：把 jpg / png 复制进「照片」文件夹，再双击运行

不需要安装 Python，不需要联网，不需要任何配置。


【这是做什么的】

基于开源框架 DeepFace（MIT 协议，作者 Sefik Ilkin Serengil）的人脸识别演示程序：

  · 人脸检测        — 定位照片中的人脸位置（OpenCV Haar 级联）
  · 属性分析        — 估计年龄、性别、情绪（7 类）三个属性
  · 特征提取        — 用 Facenet 把人脸编码成 128 维特征向量
  · 人脸比对        — 两张照片的特征向量算余弦距离，小于 0.4 判定为同一人


【文件夹里都是什么】

  双击运行.bat          ← 启动入口，双击它
  main.py               ← 程序代码
  照片\                 ← 放待分析的图（自带 2 张示例，可自行增删）
  结果图\               ← 自动生成的标注图
  说明.md               ← 实验报告（实验目的、原理、结果数据）
  python\               ← 内置的 Python 3.14 运行环境 + 全部依赖库
  models\               ← 人脸模型权重（已内置，所以不用联网下载）

  说明：python 和 models 这两个文件夹不要删、不要改名，
        程序靠它们运行。总占用约 1.5 GB。


【运行环境要求】

  · Windows 10 / 11 64 位
  · 内存 4 GB 以上（加载模型时峰值约 2 GB）
  · 无需显卡，纯 CPU 运行；单张照片约 1 秒钟


【常见问题】

  Q: 双击后窗口一闪就没了？
  A: 说明程序报错了。用鼠标右键「双击运行.bat」→ 以管理员身份运行试试；
     或者在文件夹空白处按住 Shift 右键 → 「在此处打开 PowerShell 窗口」，
     输入：.\python\python.exe main.py   再回车，就能看到具体错误。

  Q: 杀毒软件报警？
  A: 程序里带了一个完整的 Python 解释器，部分杀软会对未签名的 exe 敏感。
     本程序只在本机读写文件，不联网、不上传任何照片。选择「允许」即可。

  Q: 提示"照片文件夹里还没有图片"？
  A: 把照片复制进「照片」文件夹就行，支持 jpg / jpeg / png / bmp / webp。

  Q: 结果不准？
  A: 年龄和性别是统计估计值，受光线、角度、妆容影响较大。
     正脸、清晰、光线均匀的照片效果最好；戴口罩或侧脸容易检测不到。
